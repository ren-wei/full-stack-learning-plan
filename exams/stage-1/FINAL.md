# 阶段一验收考试：前端基础诊断卷

> 可参考资料：MDN 中文文档（https://developer.mozilla.org/zh-CN/）和自己整理的笔记。  
> 禁止使用：AI 工具、搜索引擎、阶段一两个项目的源码、任何框架或组件库

> 建议时间：55 分钟（小题 30 分钟，实战题 25 分钟），可以分两次完成。  
> 范围：语义化 HTML、选择器与盒模型、Flex 布局、响应式、原生 JavaScript、DOM 与事件、调试与 Git。  
> 题目特点：27 道小题加 1 道组件级实战题，小题不出选择题，每题都要写代码片段或写出确定结果。  
> 考试目的：定位具体缺口，判断是否需要补练、补哪一块，而不是给出一个模糊的总分。

## 一、考试要求

- 独立完成，可以查文档，但不允许翻看阶段一两个项目的源码。
- 小题直接把代码或结果写在题目下方，写得出来就写，不要编造。
- 实战题必须提交可运行的文件，不接受只写思路。

## 四、组件级实战题（第 28 题，25 分钟，100 分）

用给定的 HTML 骨架完成一个“课程卡片组件”。骨架可以直接使用，如需微调可以改，但**不允许手写 4 个卡片**。

### 给定文件

```html
<!-- index.html -->
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>课程卡片组件</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <main class="container">
    <h1 class="title">课程列表</h1>
    <div class="course-list" id="course-list"></div>
  </main>
  <script src="main.js"></script>
</body>
</html>
```

```js
// 数据结构，写在 main.js 顶部
const courses = [
  { id: 1, name: 'HTML 与 CSS 基础', duration: '12 小时', tags: ['盒模型', 'Flex'] },
  { id: 2, name: 'JavaScript 基础', duration: '16 小时', tags: ['数组', '函数'] },
  { id: 3, name: 'DOM 与事件', duration: '8 小时', tags: ['事件', '调试'] },
  { id: 4, name: '2048 项目实战', duration: '20 小时', tags: ['状态', '测试'] },
];
```

### 要求

1. **数据渲染（30 分）**：用 JavaScript 遍历 `courses`，把每张卡片插入 `#course-list`。每张卡片包含封面色块 `.card__cover`、课程名 `.card__title`、时长 `.card__meta` 和技能标签 `.tag`，标签数量按数据生成。
2. **布局与视觉（25 分）**：桌面端每行 3 张卡片，卡片间距 20px；封面色块固定 16:9 比例；卡片有 1px 边框、8px 圆角和轻微阴影。
3. **响应式（15 分）**：宽度 ≤600px 时每行 1 张卡片，页面不出现横向滚动。
4. **交互与状态（20 分）**：点击任意卡片给它添加 `is-active` 类并显示明显高亮，同时保证任何时刻最多只有一张卡片处于选中状态。
5. **可读性（10 分）**：函数职责单一、命名清晰、没有复制粘贴的大段重复代码。

### 交付

- 提交 `index.html`、`style.css`、`main.js`。
- 至少 2 次 Git 提交：数据渲染、样式与交互。

## 五、判读规则

小题按模块统计正确率（该模块答对题数 ÷ 该模块题数），实战题按第 28 题得分判断。

| 小题结果 | 实战题结果 | 建议行动 |
| --- | --- | --- |
| 全部模块 ≥80% | 完成 | 直接开始阶段二，不需要补练 |
| 个别模块 <50% | 完成 | 只补该模块，半天到 1 天 |
| 全部模块 ≥80% | 未完成 | 补 2-3 天，重点练 DOM 渲染与事件 |
| 多个模块 <60% | 未完成 | 按“验收 + 重做”方式补 5 天后再考一次 |

模块与补练内容对应：

| 模块 | 正确率低说明什么 | 补练方式 |
| --- | --- | --- |
| A 语义化 HTML | 结构意识薄弱 | 用语义标签改写一个已有页面结构 |
| B 选择器与盒模型 | 尺寸算不清、选择器写不准 | 重做盒模型计算题 + 卡片样式练习 |
| C Flex 与布局 | 布局思路未形成 | 独立完成 3 个布局小练习（导航、卡片列表、两栏） |
| D 响应式 | 适配靠试 | 用媒体查询改造已有页面，并解释断点取值 |
| E JavaScript 基础 | 数组与函数不熟 | 重做 2048 的移动与合并逻辑 |
| F DOM 与事件 | 交互写不出来 | 重做待办事项列表练习 |
| G 调试与 Git | 工具链不熟 | 用开发者工具排查 3 个真实报错并重新提交 Git |
