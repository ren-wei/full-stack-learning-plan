## 需要掌握的知识点

### 数据库与表

- 数据库、表、行、列的关系
- MySQL 的登录、退出、查看数据库和切换数据库
- 常用数据类型：`int`、`bigint`、`varchar`、`char`、`date`、`datetime`、`decimal`
- 主键、自增、非空、唯一、默认值和外键约束
- 使用 `create table`、`alter table`、`drop table` 管理表结构
- 字符集和排序规则（建议统一使用 `utf8mb4`）

### SQL 基础

- `insert` 单行和多行插入
- `update` 结合 `where` 精准修改，避免全表更新
- `delete` 与 `truncate` 的区别
- `select` 基本结构：字段、表名、条件、排序
- `where` 中的比较、逻辑、范围、模糊和空值判断
- `order by` 多字段排序和升降序
- `limit` 分页写法与偏移量计算
- 别名、去重和常用字符串、日期、数值函数

### 统计与多表查询

- `count`、`sum`、`avg`、`max`、`min`
- `group by` 分组和 `having` 过滤分组结果
- `where` 与 `having` 的执行顺序差异
- 内连接 `inner join` 与左连接 `left join`
- 一对多关系下统计结果出现重复行的原因
- 子查询：标量子查询、`in` 子查询、`exists` 子查询的基本用法
- 联表查询与多次单表查询的选择依据

### 事务与索引

- 事务的四个特性（原子性、一致性、隔离性、持久性）
- `start transaction`、`commit`、`rollback`
- 事务在转账、批量导入等场景中的作用
- 索引的作用和基本创建方式
- 主键索引与唯一索引
- 索引不是越多越好的原因

## 必做练习

1. **环境准备**：启动 MySQL 服务，使用命令行创建数据库并以 `utf8mb4` 字符集建库。
2. **建表**：创建 `student`、`course`、`score` 三张表，为学号、课程编号设置唯一约束。
3. **数据初始化**：向三张表插入至少 10 名学生、3 门课程和 20 条成绩记录。
4. **单表查询**：查询全部学生、按年龄排序、只查询前 5 条、查询指定班级的学生。
5. **条件查询**：查询成绩在 60-80 分之间的记录、查询姓名包含“张”的学生、查询班级为空的学生。
6. **更新与删除**：修改指定学号学生的班级，删除一条指定成绩，并说明如何避免误操作全表。
7. **聚合统计**：统计学生总数、每门课程的平均分、最高分和最低分。
8. **分组查询**：按班级统计人数，并只显示人数大于 2 的班级。
9. **多表查询**：查询每名学生的姓名、课程名和成绩，并输出每名学生的总分。
10. **子查询**：查询平均分高于全体平均分的学生，查询没有成绩记录的学生。
11. **分页查询**：按总分降序，每页 5 条，输出第 1 页和第 2 页的结果。
12. **事务验证**：使用事务插入一组数据后回滚，验证数据未写入；再提交一次，验证数据已写入。
