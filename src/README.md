# 大一计算机专业全栈工程师学习路线

## 路线说明

本路线面向已掌握 C 语言和数据结构的计算机专业大一学生，计划通过约 8-9 个月的系统学习，逐步形成 Java 后端与 Vue 前端的全栈开发能力，并为实习求职做好准备。

路线的顺序是“前端基础 → Java → 后端进阶 → 前端工程化”：Java 之后直接进入后端主线，保证即使后期时间不足，后端能力也已经完整，可以先投递后端实习，再补 Vue 和全栈项目。

README 仅展示整体路线。每个阶段的知识安排、练习任务、验收标准和执行计划，请查看对应阶段的详细计划。

| --- | --- | --- | --- | --- |

## 阶段一：前端入门

- **核心目标**：理解网页结构、样式与交互，能够使用原生前端技术完成基础项目
- **技术方向**：HTML、CSS、JavaScript、浏览器开发者工具
- **验收项目**：根据提供的官网蓝湖设计图完成纯静态页面还原；使用原生 JavaScript 实现 2048 游戏，并根据对应蓝湖设计图完成界面还原
- **详细计划**：[stage-1/PLAN.md](stage-1/PLAN.md)

## 阶段二：Java 基础与进阶

- **核心目标**：建立面向对象思维，掌握 Java 核心语法与进阶特性，并能够使用 Maven 组织工程
- **技术方向**：Java SE、集合进阶、Lambda 与 Stream、多线程、反射注解动态代理、Maven、JUnit、Git
- **验收项目**：控制台版学生信息管理系统（集合 + 文件持久化），并在阶段内升级为 Maven + mini IOC/AOP 版本
- **详细计划**：[stage-2/PLAN.md](stage-2/PLAN.md)

## 阶段三：后端进阶与全栈整合

- **核心目标**：掌握数据库访问与主流 Java Web 开发技术，完成博客系统后端与部署
- **技术方向**：MySQL、JDBC、HTTP 与 Servlet 基础、Spring Boot、MyBatis-Plus、JWT、Redis、Linux 与 Nginx、Docker（可选）
- **验收项目**：全栈个人博客系统的后端接口与部署
- **时间与裁剪**：共 11 周，第 1-9 周为必备内容，第 10 周为项目整理，第 11 周（Linux、Nginx、Docker）为可选
- **详细计划**：[stage-3/PLAN.md](stage-3/PLAN.md)

## 阶段四：前端工程化

- **核心目标**：掌握组件化与模块化开发方式，能够独立开发现代前端应用
- **技术方向**：Node.js、Vite、Vue 3、Vue Router、Pinia、Axios、Element Plus
- **验收项目**：博客系统前端，并与阶段三后端联调上线
- **详细计划**：[stage-4/PLAN.md](stage-4/PLAN.md)

## 阶段五：AI Agent 提效

- **核心目标**：理解 AI Agent 的基本工作方式，能够将其应用于学习和开发流程，提高交付效率
- **技术方向**：提示词编写、上下文管理、任务拆解、工具调用、代码审查、结果验证
- **验收项目**：使用 AI Agent 对已有项目完成一次需求分析、开发、调试和文档整理
- **详细计划**：[stage-5/PLAN.md](stage-5/PLAN.md)

## 备选项目

主线之外的项目，按需选做，不计入阶段验收。备选项目数据库统一使用 PostgreSQL 16，和阶段三的 MySQL 方言不同，开始前先补齐 PostgreSQL 基础。可以先看 [整套作品设计](backup-projects/PORTFOLIO.md) 了解模块组合方式，再选择单项练习。

| 项目 | 练习重点 |
| --- | --- |
| [后台管理模板](backup-projects/ADMIN_TEMPLATE.md) | 登录鉴权、RBAC、通用 CRUD、审计 |
| [订单与库存系统](backup-projects/ORDER_INVENTORY.md) | 订单状态机、库存并发、支付幂等 |
| [文件上传存储与短链分享](backup-projects/FILE_SHARE.md) | MinIO 上传、短链分享、下载鉴权 |
| [预约订座系统](backup-projects/BOOKING.md) | 时段建模、并发占位、取消释放 |
| [问卷系统](backup-projects/SURVEY.md) | 动态表单、版本、配额、统计导出 |
| [视频播放器](backup-projects/VIDEO_PLAYER.md) | HLS 转码、播放器控制、续播和鉴权 |
| [审批流程](backup-projects/APPROVAL_WORKFLOW.md) | 状态机、多级审批、并发与审计 |
| [聊天室](backup-projects/CHAT_ROOM.md) | WebSocket、消息可靠性、在线状态 |

建议顺序：后台管理模板 → 文件上传存储 → 订单与库存 → 预约订座 → 问卷；视频播放器、审批流程和聊天室按方向选做。

## 求职准备

求职准备贯穿整个学习过程，重点包括算法练习、计算机基础知识复习、项目总结、简历优化和模拟面试。建议从阶段二开始持续积累，阶段三完成后（具备可运行的后端项目时）即开始投递后端实习，阶段四边投递边补前端与全栈项目。
